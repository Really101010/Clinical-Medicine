<span style="font-size: 18px; color: #FFDEDE">甲状腺腺瘤</span>
	甲状腺滤泡上皮来源的常见<span style="text-decoration: underline;">良性肿瘤</span> 肿瘤生长缓慢 随吞咽活动而上下移动
	中青年女性多见，多单发，生长缓慢
	大体观：
		单发 圆形或类圆形（<mark style="background-color: #1A4F10; color: white">形态规则</mark>） 实性切面 <mark style="background-color: #1A4F10; color: white">有完整包膜</mark> 常压迫周围组织，直径一般3~5cm。
		色暗红或棕黄
		可并发出血、囊性变、钙化和纤维化
	镜下观

| 组织学类型   | 别称                                                                     | 病理变化                                                                                                                                    |
| ------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 单纯型腺瘤   | 正常<mark style="background-color: #705A16; color: white">大小滤泡</mark>型腺瘤 | 肿瘤包膜完整，瘤组织由大小一致、排列拥挤、内含胶质，与正常甲状腺相似的滤泡构成                                                                                                 |
| 胶样型腺瘤   | 巨滤泡型腺瘤                                                                 | 肿瘤组织由大滤泡或大小不一的滤泡组成，滤泡内充满胶质                                                                                                              |
| 胎儿型腺瘤   | 小滤泡型腺瘤                                                                 | 肿瘤组织主要由小而一致、仅含<span style="text-decoration: underline;">少量胶质</span>或没有胶质的小滤泡组成，上皮细胞为立方形，与胎儿甲状腺组织类似                                      |
| 胚胎型腺瘤   | 梁状和实性腺瘤                                                                | 瘤细胞小，大小较一致， 分化好，呈片状或条索状；偶见不完整的小滤泡，<span style="text-decoration: underline;">无胶质</span>，间质疏松呈水肿状                                         |
| 嗜酸细胞型腺瘤 | Hirthle细胞腺瘤                                                            | 瘤细胞大而呈<span style="font-weight: bold; text-decoration: underline;">多角形</span>，核小，胞质丰富，嗜酸性，内含嗜酸性颗粒；电镜下见嗜酸性细胞内有丰富的线粒体；瘤细胞排列成索网状或巢状，很少形成滤泡 |
| 非典型腺瘤   | ——                                                                     | 瘤细胞丰富，有轻度非典型增生，可见核分裂象；瘤细胞排列成索或巢片状，不形成滤泡，间质少，<span style="font-weight: bold; text-decoration: underline;">无包膜和血管侵犯</span>                |
结节性甲状腺肿与甲状腺瘤的鉴别

|       | 结节性甲状腺肿                                                             | 甲状腺瘤                                                              |
| ----- | ------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 结节数目  | 常为多发                                                                | 常为单发                                                              |
| 包膜    | <mark style="background-color: #1A4F10; color: white">多无完整包膜</mark> | <mark style="background-color: #1A4F10; color: white">完整包膜</mark> |
| 结节内   | 滤泡大，不一致                                                             | 滤泡小，一致                                                            |
| 周围甲状腺 | 无压迫，内外一致，临近组织有相似病变                                                  | 压迫，内外不一致，临近组织没有相似病变                                               |
