一、按肌力减退程度
- **完全性瘫痪**：肌力 0～1 级，肌肉完全不能收缩或仅有轻微收缩。
- **不完全性瘫痪（轻瘫）**：肌力 2～4 级，肌肉能收缩但无法对抗阻力或完成正常动作。

---
 二、按瘫痪部位和神经损害组合

| 类型        | 表现                                                                       | 常见病因                                                                           |
| --------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| **单瘫**    | 单一肢体（上肢或下肢）瘫痪                                                            | 脊髓灰质炎、周围神经损伤                                                                   |
| **偏瘫**    | 一侧上、下肢瘫痪，常伴有<span style="font-size: 16px; color: #FF0000">同侧</span>脑神经损害 | <mark style="background-color: #1A4F10; color: white">颅内</mark>病变（如脑卒中）、大脑半球损伤 |
| **交叉性偏瘫** | 一侧肢体瘫痪，**伴有对侧脑神经损害**                                                     | <mark style="background-color: #1A4F10; color: white">脑干</mark>病变（如脑干梗死、炎症）    |
| **截瘫**    | 双侧下肢瘫痪，通常为脊髓横贯性损伤                                                        | 脊髓外伤、脊髓炎、脊髓压迫症                                                                 |
