| 对比项                                                               | A型胃炎（慢性胃体炎）                                                          | B型胃炎（慢性胃窦炎）                                                    |
| :---------------------------------------------------------------- | :------------------------------------------------------------------- | :------------------------------------------------------------- |
| 别称                                                                | 慢性胃体炎                                                                | 慢性胃窦炎                                                          |
| <mark style="background-color: #705A16; color: white">好发部位</mark> | <mark style="background-color: #1A4F10; color: white">胃体部、胃底部</mark> | 胃窦部                                                            |
| 基本病理变化                                                            | 胃黏膜萎缩变薄、腺体减少                                                         | 胃黏膜萎缩变薄、腺体减少                                                   |
| 发病率                                                               | 少见                                                                   | 很常见                                                            |
| <mark style="background-color: #705A16; color: white">病因</mark>   | <mark style="background-color: #1A4F10; color: white">自身免疫</mark>    | H. P.感染（占60%~70%）                                              |
| 血清中自身抗体                                                           | 阳性（>90%）                                                             | 阴性                                                             |
| 抗内因子抗体（IFA）                                                       | <mark style="background-color: #1A4F10; color: white">阳性</mark>      | <span style="font-size: 16px; color: grey">阴性</span>           |
| 抗壁细胞抗体（PCA）                                                       | <mark style="background-color: #1A4F10; color: white">阳性</mark>      | <span style="font-size: 16px; color: grey">阴性</span>           |
| 胃内G细胞增生                                                           | 有                                                                    | 无                                                              |
| 血清胃泌素水平                                                           | 高                                                                    | 低                                                              |
| 胃酸分泌                                                              | <span style="font-size: 16px; color: #FF0000">明显降低</span>            | 中度降低或正常                                                        |
| 血清VitB₁₂水平                                                        | <span style="font-size: 16px; color: #FF0000">降低</span>              | 正常                                                             |
| 恶性贫血                                                              | <span style="font-size: 16px; color: #D5E0A0">常有</span>              | 无                                                              |
| 伴发消化性溃疡                                                           | 无                                                                    | <mark style="background-color: #1A4F10; color: white">高</mark> |
大体观：黏膜灰色或灰绿色；黏膜变薄，皱襞变浅；表面呈细颗粒状，黏膜下<span style="text-decoration: underline;">小血管清晰可见</span>
镜下观：
	<mark style="background-color: #1A4F10; color: white">黏膜变薄 腺体萎缩</mark>（特异性标准）<mark style="background-color: #1A4F10; color: white">纤维组织增生</mark>
	<mark style="background-color: #1A4F10; color: white">固有膜内淋巴细胞 浆细胞浸润</mark>，可形成淋巴滤泡
	<mark style="background-color: #705A16; color: white">肠上皮化生</mark> ：
		病变区胃黏膜上皮被肠型腺上皮（杯状细胞/吸收上皮细胞/潘氏细胞）替代的现象
		完全化生：化生上皮同时有杯状细胞和吸收上皮细胞
		不完全型化生：<span style="text-decoration: underline;">只有杯状细胞</span>（分化不成熟，易癌变）
			胃型化生（IIa 分泌中性黏液）
			结肠型化生（IIb 分泌硫酸黏液）
	<mark style="background-color: #1A4F10; color: white">假幽门腺化生</mark>：胃体或胃底部的壁细胞和主细胞消失，为类似幽门腺的黏液分泌细胞所取代
