大小关节均可受累（常见于手部小关节、腕、膝、踝等，但髋、肩等大关节也可受累）；
多关节受累（多为对称性、游走性）；
非侵蚀性、非畸形性（极少引起骨质破坏，与类风湿关节炎的侵蚀性畸形不同），疼痛明显但X线多无关节侵蚀。

| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 好发人群           | 育龄期女性（20~40岁）                                                                                                                                                                           | 女性（40~60岁）                                                                                                                                                                          |
| 关节特征           | <mark style="background-color: #1A4F10; color: white">大小关节</mark>均可受累、<mark style="background-color: #1A4F10; color: white">多关节、对称性</mark>；  <br>非侵蚀性、非畸形性（即使有Jaccoud关节病，也是可复性畸形，无骨质破坏） | <mark style="background-color: #1A4F10; color: white">小关节</mark>受累为主（腕、掌指、近端指间关节）；  <br><mark style="background-color: #1A4F10; color: white">侵蚀性、破坏性</mark>，晚期可出现尺侧偏斜、天鹅颈畸形、纽扣花样畸形 |
| 特异性自身抗体        | 抗dsDNA抗体（活动性标志）、抗Sm抗体（诊断标志物，特异性95%）、抗Ro/抗La                                                                                                                                             | 抗CCP抗体（早期诊断、高特异性）、类风湿因子（RF）（<span style="font-weight: bold; text-decoration: underline;">非特异性，阳性可见于其他结缔组织病</span>）                                                                  |
| 系统脏器受累         | <mark style="background-color: #1A4F10; color: white">肾脏</mark>（狼疮肾炎最常见、最严重）、血液系统（三系减少）、神经系统（癫痫、精神障碍）、浆膜炎（心包炎/胸膜炎）、面部蝶形红斑、光过敏、口腔溃疡                                                      | 关节外表现：类风湿结节（肘部皮下多见）、肺间质纤维化、干燥综合征、心血管受累（少见肾损害）                                                                                                                                       |
| [皮肤](皮肤.md)/黏膜 | 蝶形红斑（跨鼻梁）、盘状红斑、光过敏、口腔/鼻溃疡                                                                                                                                                               | 无特征性面部皮疹，可见皮下类风湿结节                                                                                                                                                                  |
| 雷诺现象           | 多见（约30%~50%）                                                                                                                                                                            | 少见，或仅见于合并其他结缔组织病时                                                                                                                                                                   |
| X线检查           | 多无骨质破坏，仅见软组织肿胀或骨质疏松                                                                                                                                                                     | 早期：关节周围软组织肿胀、骨质疏松；  <br>晚期：关节间隙变窄、骨质侵蚀、半脱位                                                                                                                                          |
| 贫血类型           | 自身免疫性溶血性贫血（Coombs试验阳性）或慢性病贫血                                                                                                                                                            | 慢性病贫血（正细胞正色素性）                                                                                                                                                                      |
| 治疗原则           | 羟氯喹为基础用药；  <br>狼疮肾炎用糖皮质激素+环磷酰胺/霉酚酸酯；  <br>避免日晒、妊娠需严密监测                                                                                                                                  | 甲氨蝶呤（MTX） 为首选改善病情抗风湿药（DMARDs）；  <br>生物制剂（TNF-α拮抗剂）用于难治性RA                                                                                                                           |
