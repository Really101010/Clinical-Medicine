<mark style="background-color: #705A16; color: white">升浮</mark>类药（性味多**辛、甘，温、热**，作用趋向**向上、向外**）

| 药物      | 性味       | 升浮依据（功效对应）                        |
| ------- | -------- | --------------------------------- |
| **桂枝**  | 辛、甘，温    | 发汗解肌（向外发散），助阳化气（向上）               |
| **羌活**  | 辛、苦，温    | 解表散寒（向外），祛风胜湿（向上，治头痛项强）           |
| **防风**  | 辛、甘，微温   | 祛风解表（向外），止痉（向外散风）                 |
| **柴胡**  | 微辛、微苦，微寒 | 疏散风热（向外），**升阳举陷**（**向上**，治脱肛、久泻）  |
| **菊花**/ | 辛、甘、苦，微寒 | 疏散风热（向外），平肝明目（向上）                 |
| **藿香**  | 辛，微温     | 化湿解暑（向外透散），辛温解表（向外）               |
| **苍术**/ | 辛、苦，温    | 发散风寒（向外），燥湿健脾（向上，升脾阳）             |
| **黄芪**/ | 甘，微温     | **补气升阳**（**向上**，治中气下陷），固表止汗（向外固护） |
| **升麻**  | 辛、甘，微寒   | （教材示例，升阳举陷，向上）                    |
| **桔梗**  | 苦、辛，平    | （教材示例，载药上行，向上）                    |

> **升浮药特点**：多为**解表药、升阳药**，主治表证（向外）和**气虚下陷证**（向上）。

<mark style="background-color: #705A16; color: white">沉降</mark>类药（性味多**酸、苦、咸、涩，寒、凉**，作用趋向**向下、向内**）

| ----------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------- |
| **大黄**/                                                           | 苦，寒      | **泻热通便**（**向下**推荡积滞），凉血解毒（向内清泄）                                                    |
| <span style="font-size: 16px; color: #FF0000">1</span>**苏子**      | 辛，温      | （教材示例，**降气平喘**，向下）                                                                 |

| **枳实**                                                            | 苦、辛、酸，微寒 | **破气消积**（**向下**推荡），化痰散痞（向内消散）                                                      |

| **肉桂**                                                            | 辛、甘，大热   | **引火归原**（**向下**引虚火归肾），温肾纳气（向下纳气归元）                                                 |

| **天麻**/                                                           | 甘，平      | 平肝息风（向内平息，治内风）                                                                     |
| **沙参**                                                            | 甘，微寒     | <mark style="background-color: #1A4F10; color: white">养阴</mark>清肺（向内滋润），益胃生津（向下滋润） |
| **黄精**/                                                           | 甘，平      | 补气<mark style="background-color: #1A4F10; color: white">养阴</mark>（向内填补），益肾（向下补下焦）  |
| **金银花**                                                           | 甘，寒      | 清热解毒（向内清解热毒）                                                                       |

> **沉降药特点**：多为**泻下药、降逆药、利水药、清热药**，主治便秘（向下）、呕吐咳喘（向下）、水肿（向下）、热毒（向内）。

<mark style="background-color: #705A16; color: white">双向</mark>作用类（升降浮沉不明显，或随炮制、配伍而变化）

| 药物      | 说明                       |
| ------- | ------------------------ |
| **陈皮**  | 理气健脾（升脾气）、燥湿化痰（降肺气），升降并调 |
| **香附**/ | 疏肝解郁（升散），调经止痛（沉降），升降兼施   |
| **人参**  | 大补元气（升补），安神益智（沉降），双向调节   |
| **白术**  | 健脾益气（升），燥湿利水（降），升降同用     |
