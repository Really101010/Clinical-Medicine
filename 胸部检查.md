1.胸廓
	正常人的胸廓，前后径：左右径=1：1.5 [肺气肿](肺气肿)
	<span style="font-size: 18px; color: #FAF9C6">桶状胸</span>：胸廓的前后径增大，以至和左右径几乎相等，甚至超过左右径，胸廓呈圆桶形，肋间隙增宽且饱满。常见于[[慢性阻塞性肺气肿]]及[[支气管哮喘]]发作时
	<span style="font-size: 18px; color: #FAF9C6">扁平胸</span>：胸廓呈扁平状，其前后径不及左右径的一半。常见于<mark style="background-color: #1A4F10; color: white">瘦长体型者、慢性消耗性疾病</mark>（如[[肺结核]]）
	<span style="font-size: 18px; color: #FAF9C6">佝偻病胸</span><span style="font-size: 16px; color: grey">（缺钙，骨骺膨大）</span>[佝偻病](佝偻病.md)
		<span style="font-weight: bold; text-decoration: underline;">佝偻病串珠</span>：沿胸骨两侧各肋软骨与肋骨交界处常隆起，形成串珠状
		<span style="font-weight: bold; text-decoration: underline;">漏斗胸</span>：胸骨剑突处显著内陷，形似漏斗
		<span style="font-weight: bold; text-decoration: underline;">鸡胸</span>：胸廓的前后径略长于左右径，上下距离较短，胸骨下端常向前突，胸廓前侧壁肋骨凹陷
2.肺和胸膜—视诊
	呼吸运动
		[呼吸困难](呼吸困难.md)
			吸气困难：可见三凹征（胸骨上窝、锁骨上窝、肋间隙）。常见于气管梗阻，如气管肿瘤、异物
			呼气困难：常见于下呼吸道梗阻，如[[支气管哮喘]]、[[慢阻肺]]。
		**胸式呼吸减弱：肺或胸膜疾病**，如[[肺炎]]、重症[[肺结核]]、[[胸膜炎]]、肋骨骨折
		**腹式呼吸减弱：腹部疾病**，如[[腹膜炎]]、大量[[腹水]]、腹腔内巨大占位、[[妊娠]]晚期
	呼吸频率
		成人呼吸频率为 12~20 次/分；呼吸与脉搏之比为 1:4。新生儿可达 44 次每分
		<mark style="background-color: #705A16; color: white">深大呼吸（Kussmaul 呼吸）</mark>:  呼吸<span style="font-weight: bold; text-decoration: underline;">深快</span>，当严重代谢性酸中毒时，亦出现深而大的呼吸，此因细胞外液碳酸氢不足，pH 降低，通过肺脏排出 CO2，进行代偿，以调节细胞外酸碱平衡之故。见于[[代谢性酸中毒]]、[[糖尿病]]酮中毒、[[尿毒症]]酸中毒等。
	呼吸节律
		<mark style="background-color: #705A16; color: white">潮式呼吸（Cheyne‐Stokes呼吸，陈-施呼吸）</mark>:  一种<span style="font-weight: bold; text-decoration: underline;">由浅慢逐渐变为深快，然后再由深快转为浅慢，随之出现一段呼吸暂停</span>后，又开始加上变化的周期的呼吸。潮式呼吸周期可长达 30 秒至 2 分钟，暂停期可持续5～30 秒。多见于[[脑炎]]，[[脑膜炎]]，[[颅内压增高]]等。
		<mark style="background-color: #705A16; color: white">间停呼吸（biots 呼吸，比奥呼吸）</mark>：表现为<span style="font-weight: bold; text-decoration: underline;">有规律呼吸几次后，突然停止一段时间</span>，又开始呼吸，即周而复始的间停呼吸。<mark style="background-color: #1A4F10; color: white">临终前危象</mark>。
3.触诊
	<span style="font-size: 18px; color: #FAF9C6">语音语颤</span>.
		定义:  被检查者发出语音时，声波起源于喉部，沿气管，支气管及肺泡传到胸壁所引起的共鸣的震动，可由检查者的手触及，故又称触觉震颤。<span style="text-decoration: underline;">强弱主要取决于气管、支气管是否通畅，胸壁传导是否良好。</span>
		正常人：肩胛区、左右胸骨旁第 1 和第 2 肋间隙最强，肺底最弱
		<span style="font-size: 18px; color: #D5E0A0">语颤减弱</span>见于:
			  ①肺泡内含气量过多，如[肺气肿](肺气肿.md)；
			  ②支气管阻塞，如阻塞性[[肺不张]]，[[慢阻肺]]；
			  ③大量[[胸腔积液]]或[[气胸]]；
			  ④高度[胸膜粘连、增厚](胸膜粘连、增厚)；
			  ⑤胸壁<mark style="background-color: #1A4F10; color: white">皮下气肿</mark>。
		<span style="font-size: 18px; color: #D5E0A0">语颤增强</span>见于:  
			①<mark style="background-color: #1A4F10; color: white">肺实变</mark>，如大叶性[[肺炎]]实变期，[[肺梗死]]等；
			②浅而大的<mark style="background-color: #1A4F10; color: white">肺空洞</mark>如[[肺结核]]，[[肺脓肿]]所形成的空洞。（前提是空洞与气管相通产生共鸣）
		语音共振和语音震颤在绝大多数病变中的变化方向是一致的
4.叩诊
	正常	
		清音，浊音，实音，鼓音。
		胸上部的叩诊音较下部相对混浊；右肺上部叩诊音较左肺上部混浊；背部叩诊音较前胸混浊（肌肉发达）。
		正常肺下界（锁骨中线第 6 肋、腋中线第8 肋、肩胛线第 10 肋）
	异常
		<mark style="background-color: #705A16; color: white">鼓音</mark>常见于肺空洞，必须具备肺内空洞腔径大于3 cm，靠近胸壁，如<mark style="background-color: #1A4F10; color: white">空洞型</mark>[[肺结核]]；[[气胸]]。
		<mark style="background-color: #705A16; color: white">过清音</mark>常见于[[肺气肿]]、[支气管哮喘](支气管哮喘)。
		诊<mark style="background-color: #705A16; color: white">浊音或实音</mark>：肺内大面积含气量减少的病变，如[[肺炎]]、[[肺不张]]、[[肺梗死]]、[[肺结核]]、[[肺水肿]]及[[肺硬化]]；以及[[胸腔积液]]，不含气的占位如[[肿瘤]]。
		肺<mark style="background-color: #705A16; color: white">下界的移动</mark>范围（6‐8cm）
			移动范围<mark style="background-color: #705A16; color: white">减小</mark>：**[[慢阻肺]]疾病、[[肺不张]]、[[肺纤维化]]、[[肺炎]]、[[肺水肿]]**
			<mark style="background-color: #705A16; color: white">不能</mark>叩得：**大量[[胸腔积液]]、积气、广泛[胸膜粘连、增厚](胸膜粘连、增厚)**
			<mark style="background-color: #705A16; color: white">Damoiseau曲线</mark>——积液，实音区
			<mark style="background-color: #705A16; color: white">Garland triangle</mark>——实变，浊音鼓音区

异常呼吸音听诊意义
	异常肺泡呼吸音
		(1)肺泡呼吸音减弱或消失：如胸廓活动受限、呼吸肌疾病、<mark style="background-color: #1A4F10; color: white">支气管阻塞</mark>（[[慢阻肺]]）<span style="font-size: 16px; color: grey">→减弱</span>、<mark style="background-color: #1A4F10; color: white">压迫性肺膨隆胀不全</mark>（[[胸腔积液]]、[[气胸]]）<span style="font-size: 16px; color: grey">→消失</span>、腹部疾病
		(2)肺泡呼吸音增强：如[[发热]]、代谢性酸中毒，[[贫血]]等
		(3)呼吸音延长：如下呼吸道阻塞，痉挛或狭窄，[[支气管炎]]，[[支气管哮喘]]
		(4)粗糙性呼吸音，见于为支气管黏膜轻度水肿或炎症浸润造成<span style="text-decoration: underline;">不光滑或狭窄</span>，见于[[支气管炎]]早期
	异常支气管呼吸音（管样呼吸音）
		(1)<mark style="background-color: #1A4F10; color: white">肺组织实变</mark>：通过致密的肺传导至体表，如大叶性[[肺炎]]
		(2)肺内大空腔：与气管相同产生共鸣，如[[肺脓肿]]<mark style="background-color: #1A4F10; color: white">、空洞型</mark>[[肺结核]]
		(3)压迫性肺不张：[[胸腔积液]]

湿啰音
	①细湿啰音
		：又称小水泡音，发生于小支气管，多在吸气后期出现。
		常见于细[[支气管炎]]、支气管[[肺炎]]、[[肺淤血]]、[[肺梗死]]等
		<mark style="background-color: #705A16; color: white">Vecro 啰音</mark>：吸气后期出现的细湿啰音，**音调高**，似撕开尼龙扣带时发出的声音，最常见于<mark style="background-color: #1A4F10; color: white"><span style="font-weight: bold; text-decoration: underline;">弥漫性肺间质纤维化</span></mark>。[肺纤维化](肺纤维化)
	②捻发音:又称捻发性湿啰音或微小湿啰音，是一种极细而均匀的高音调的音响，很像用手在耳边捻搓一束头发所产生的声音，故称捻发音。
		见于[[肺炎]]早期，[[肺结核]]早期，[[肺淤血]]，纤维性肺泡炎。
		正常老年人长期卧床者，肺底亦可闻及。
干啰音
	机制：管腔**狭窄或部分阻塞**，气体进出时产生**湍流**。
	病理基础：粘膜充血水肿、分泌物增多；<span style="text-decoration: underline;">支气管平滑肌痉挛；管腔内肿瘤或异物阻塞</span>；管壁被肿大的淋巴结或肿瘤压迫
	高调干啰音（哨笛音，小气道） 
	低调干啰音（鼾音，大气道）
	常见于：[[支气管哮喘]]、[慢性支气管炎](慢性支气管炎)、[[心源性哮喘]]（吸气湿啰音，呼气干啰音）
<mark style="background-color: #705A16; color: white">胸膜磨擦音</mark>
	胸膜磨擦音在吸气和呼气时都可听到，以吸气末或呼气初较为明显，屏住呼吸时消失；<span style="font-weight: bold; text-decoration: underline;">前下侧胸壁最常见</span>。
	会受到体位影响
	胸膜摩擦音的临床意义:  胸膜摩擦音是<mark style="background-color: #1A4F10; color: white">干性胸膜炎</mark>的重要体征，常见于: 
		①胸膜炎症，[[结核性胸膜炎]]和化脓性胸膜炎；
		②原发性或继发性胸膜肿瘤；
		③肺部病变累及胸膜，如[[肺炎]]，[[肺梗死]]；
		④[[尿毒症]]。
