1.胸廓
	Louis角（[[胸骨角]]），[[胸部垂直线]]，[[肋间定位]]
	“上下区，上上下下窝”
		锁骨上窝、肺尖上部。锁骨下窝、肺尖下部。肩胛上区、肺尖下部。
	正常人的胸廓，前后径：左右径=1：1.5 [肺气肿](肺气肿)
	<span style="font-size: 18px; color: #FAF9C6">桶状胸</span>：胸廓的前后径增大，以至和左右径几乎相等，甚至超过左右径，胸廓呈圆桶形，肋间隙增宽且饱满。常见于[[慢性阻塞性肺气肿]]及[[支气管哮喘]]发作时
	<span style="font-size: 18px; color: #FAF9C6">扁平胸</span>：胸廓呈扁平状，其前后径不及左右径的一半。常见于<mark style="background-color: #1A4F10; color: white">瘦长体型者、慢性消耗性疾病</mark>（如[[肺结核]]）
	<span style="font-size: 18px; color: #FAF9C6">串珠胸</span><span style="font-size: 16px; color: grey">（缺钙，骨骺膨大）</span>[佝偻病](佝偻病.md)
		<span style="font-weight: bold; text-decoration: underline;">佝偻病串珠</span>：沿胸骨两侧各肋软骨与肋骨交界处常隆起，形成串珠状
		<span style="font-weight: bold; text-decoration: underline;">漏斗胸</span>：胸骨剑突处显著内陷，形似漏斗
		<span style="font-weight: bold; text-decoration: underline;">鸡胸</span>：胸廓的前后径略长于左右径，上下距离较短，胸骨下端常向前突，胸廓前侧壁肋骨凹陷
	脊柱畸形可以是前凸、后凸、侧凸。侧凸会导致胸廓不对称，前凸会导致肋间隙增宽，后凸会导致肋间隙变窄。
+ 乳房检查
	对称性：一侧肿大提示炎症、肿瘤或对侧发育不良。
	皮肤改变：
		橘皮征（桔皮样变）：乳房皮肤水肿，毛囊处凹陷 → 提示[乳腺癌](乳腺癌.md)（癌细胞侵犯皮下淋巴管）。
		酒窝征：皮肤局部凹陷 → 提示乳腺癌（Cooper韧带受侵牵拉）。
		乳头：内陷（先天性或癌性）、溢液（血性溢液警惕乳管内乳头状瘤或乳腺癌）。
	急性乳腺炎：红肿热痛 + 波动感，常见于哺乳期。
	乳腺囊性增生病：片状增厚，呈结节状，有触痛，与月经周期相关（经前加重，经后减轻）。
2.肺和胸膜—视诊
	呼吸运动
		[呼吸困难](呼吸困难.md)
			吸气困难：可见三凹征（胸骨上窝、锁骨上窝、肋间隙）。常见于气管梗阻，如气管肿瘤、异物
			呼气困难：常见于下呼吸道梗阻，如[[支气管哮喘]]、[[慢阻肺]]。
		**胸式呼吸减弱：肺或胸膜疾病**，如[[肺炎]]、重症[[肺结核]]、[[胸膜炎]]、肋骨骨折
		**腹式呼吸减弱：腹部疾病**，如[[腹膜炎]]、大量[[腹水]]、腹腔内巨大占位、[[妊娠]]晚期
	呼吸频率
		成人呼吸频率为<span style="font-size: 16px; color: #FAF9C6"> 12~20 </span>次/分；
		呼吸与脉搏之比为 1:4
		新生儿可达 44 次每分
		呼吸过速：[发热](发热.md)（体温每升1℃呼吸增约4次）、[贫血](贫血.md)、[疼痛](疼痛.md)、[甲亢](甲亢.md)、[左心衰竭](左心衰竭.md)
		呼吸过缓：[颅内高压](颅内高压.md)、麻醉镇静剂过量

3.触诊
	<span style="font-size: 18px; color: #FAF9C6">语音语颤</span>.
		定义:  被检查者发出语音时，声波起源于喉部，沿气管，支气管及肺泡传到胸壁所引起的共鸣的震动，可由检查者的手触及，故又称触觉震颤。<span style="text-decoration: underline;">强弱主要取决于气管、支气管是否通畅，胸壁传导是否良好。</span>
		正常人：<mark style="background-color: #1A4F10; color: white">肩胛区、左右胸骨旁第 1 和第 2 肋间隙最强</mark>，肺底最弱
		<span style="font-size: 18px; color: #D5E0A0">语颤减弱</span>见于:
			  ①肺泡内含气量过多，如[肺气肿](肺气肿.md)；
			  ②支气管阻塞，如阻塞性[[肺不张]]，[慢性阻塞性肺气肿](慢性阻塞性肺气肿.md)；
			  ③大量[[胸腔积液]]或[[气胸]]；
			  ④高度[胸膜粘连、增厚](胸膜粘连、增厚)；
			  ⑤胸壁<mark style="background-color: #1A4F10; color: white">皮下气肿</mark>。
		<span style="font-size: 18px; color: #D5E0A0">语颤增强</span>见于:  
			①<mark style="background-color: #1A4F10; color: white">肺实变</mark>，如大叶性[[肺炎]]实变期，[[肺梗死]]等；
			②浅而大的<mark style="background-color: #1A4F10; color: white">肺空洞</mark>如[[肺结核]]，[[肺脓肿]]所形成的空洞。（前提是空洞与气管相通产生共鸣）
		语音共振和语音震颤在绝大多数病变中的变化方向是一致的
	[[皮下气肿]]
4.叩诊
	叩痛：白血病有胸骨压痛和叩击痛
	正常	
		**清音，浊音，实音，鼓音**。
			叩击<mark style="background-color: #1A4F10; color: white">被少量含气组织覆盖的实质脏器</mark>如<span style="font-weight: bold; text-decoration: underline;">心或肝被肺边缘所覆盖的</span>部分得<mark style="background-color: #705A16; color: white">浊音</mark>
			胸上部的叩诊音较下部相对混浊（胸壁厚度差异）
			右肺上部叩诊音较左肺上部混浊
			背部叩诊音较前胸混浊（肌肉发达）
			正常人左胸下部胃泡区叩诊呈<mark style="background-color: #705A16; color: white">鼓音</mark>，又称<span style="font-size: 16px; color: #FAF9C6">Traube鼓音区</span>
		肺上界
			从<mark style="background-color: #1A4F10; color: white">斜方肌前缘中央部</mark>开始叩诊，扣出肺尖宽度，称<span style="font-size: 16px; color: #FAF9C6">Kronig峡</span>
		正常肺下界（[胸部垂直线](胸部垂直线.md)）
			肺下界<mark style="background-color: #1A4F10; color: white">移动度最大的地方在腋中线和腋后线</mark>上。（<span style="font-size: 16px; color: #FF0000">注意不是肩胛线是腋后线！！</span>），移动度取决于<span style="font-size: 16px; color: #D5E0A0">肋膈窦即肋膈隐窝</span>大小
			矮胖者肺下界可上升1肋间隙（属于正常，<span style="font-size: 16px; color: grey">上下1肋间隙</span>）
			肺下界上升见于[肺不张](肺不张.md)、[胸腔积液](胸腔积液.md)
			肺下界降低见于[慢阻肺](慢阻肺.md)、腹腔内脏下垂
			有说法是反应<span style="font-size: 16px; color: #FAF9C6">膈肌位置</span>，解释[气胸](气胸)时肺下界下移
				<span style="font-size: 16px; color: grey">（“诊断学-胸部检查”第65题）</span>.
			当大量[胸腔积液](胸腔积液.md)、[气胸](气胸)及广泛[胸膜粘连、增厚](胸膜粘连、增厚)时肺下界及其移动度**不能叩得**
		双侧肺前界
			相当于心脏浊音界
			①[肺气肿](肺气肿.md)→肺界扩大，心界减小，即浊音区缩小
			②心脏扩大，心肌肥厚，[心包积液](心包积液.md)等→肺界缩小，心界扩大，即浊音区扩大
		<span style="font-size: 16px; color: grey">强度（大→小）过清音>清音=鼓音（强）>浊音>实音（弱）</span>.
		<span style="font-size: 16px; color: grey">音调（高→低）鼓音=实音（高）>浊音>清音（低）>过清音（更低）</span>'
		<span style="font-size: 16px; color: grey">相对时限（长→短）过清音>清音（长）=鼓音>浊音>实音（短）</span>.
	异常
		支气管炎可叩得<mark style="background-color: #705A16; color: white">清音</mark>
		<mark style="background-color: #705A16; color: white">鼓音</mark>常见于肺空洞，必须具备肺内空洞腔径大于3 cm，靠近胸壁，如<mark style="background-color: #1A4F10; color: white">空洞型</mark>[[肺结核]]；[气胸](气胸)（有[胸痛](胸痛.md)）。
		<mark style="background-color: #705A16; color: white">过清音</mark>常见于[[肺气肿]]（无胸痛）、[支气管哮喘](支气管哮喘)。
		诊<mark style="background-color: #705A16; color: white">浊音或实音</mark>：肺内大面积含气量减少的病变，如[[肺不张]]、[肺梗死](肺梗死)、[[肺结核]]、[[肺水肿]]及肺硬化；以及不含气的占位如[[肿瘤]]。
			[[肺炎]]的叩击音，叩击得<mark style="background-color: #705A16; color: white">浊音</mark>
			肺实变和[[胸腔积液]]叩<mark style="background-color: #705A16; color: white">实音</mark>，音调较浊音更高，音响更弱，振动持续时间更短
			“肺内水多-浊音，肺外水多-实音”
		肺<mark style="background-color: #705A16; color: white">下界的移动</mark>范围（6‐8cm）
			移动范围<mark style="background-color: #705A16; color: white">减小</mark>：**[慢性阻塞性肺气肿](慢性阻塞性肺气肿.md)疾病、[[肺不张]]、[[肺纤维化]]、[[肺炎]]、[[肺水肿]]**
			<mark style="background-color: #705A16; color: white">不能</mark>叩得：**大量[[胸腔积液]]、积气、广泛[胸膜粘连、增厚](胸膜粘连、增厚)**
			<mark style="background-color: #705A16; color: white">Damoiseau曲线</mark>——积液，实音区
			<mark style="background-color: #705A16; color: white">Garland triangle</mark>——实变，浊音鼓音区
5.听诊
	直接听诊法 仅在某些特殊、紧急情况（如小孩，本身胸壁薄）
	正常肺部听诊可听到：气管呼吸音、支气管呼吸音、支气管肺泡呼吸音、肺泡呼吸音
	肺泡呼吸音在<mark style="background-color: #1A4F10; color: white">乳房下部和肩胛下部最强</mark>

	异常肺泡呼吸音

		(2)肺泡呼吸音增强：如[[发热]]、代谢性酸中毒，[[贫血]]等
		(3)呼吸音延长：如下呼吸道阻塞，痉挛或狭窄，[[支气管炎]]，[[支气管哮喘]]
		(4)粗糙性呼吸音，见于为支气管黏膜轻度水肿或炎症浸润造成<span style="text-decoration: underline;">不光滑或狭窄</span>，见于[[支气管炎]]早期

				<mark style="background-color: #705A16; color: white">Velcro啰音</mark>（吸气后期，**高调**撕扣带声）→ <mark style="background-color: #1A4F10; color: white">弥漫性肺间质纤维化</mark>-[肺纤维化](肺纤维化)
			②捻发音（极细高调捻发感）：[[肺炎]]/[肺结核](肺结核.md)早期、[肺淤血](肺淤血.md)、纤维性肺泡炎；正常老年人长期卧床者，肺底亦可闻及
			<span style="font-weight: bold; font-size: 16px; color: #FFDEDE">分布意义</span>：
				<span style="font-size: 16px; color: #D5E0A0">局限性湿啰音</span>：仅提示该处的局部病变，如[支气管肺炎](支气管肺炎.md)、[肺结核](肺结核.md)或[支气管扩张](支气管扩张.md)等
				<span style="font-size: 16px; color: #D5E0A0">两肺底湿啰音</span>：是由于肺泡腔渗出所致，多见于[心力衰竭](心力衰竭.md)所致[肺淤血](肺淤血.md)和[支气管肺炎](支气管肺炎.md)等疾病；[[心源性哮喘]]（吸气湿啰音，呼气干啰音）
				<span style="font-size: 16px; color: #D5E0A0">双肺满布湿啰音</span>：肺泡腔大量血浆渗出所致，多见于急性[肺水肿](肺水肿.md)			
		干啰音“高干子弟易变心”
			机制：管腔**狭窄或部分阻塞**，气体进出时产生**湍流**。
			病理基础：粘膜充血水肿、分泌物增多；<span style="text-decoration: underline;">支气管平滑肌痉挛；管腔内肿瘤或异物阻塞</span>；管壁被肿大的淋巴结或肿瘤压迫
			高调干啰音（哨笛音，小气道） 
			低调干啰音（鼾音，大气道）
			<span style="font-size: 16px; color: #D5E0A0">局限性干啰音</span>：局部支气管狭窄所致，可见于支气管内膜[结核](结核.md)或[肿瘤](肿瘤.md)等疾病
			<span style="font-size: 16px; color: #D5E0A0">双肺布满哮鸣音</span>：肺泡腔大量血浆渗出所致，见于[[支气管哮喘]]
			<span style="font-size: 16px; color: #D5E0A0">局部哮鸣音</span>：支气管[肺癌](肺癌.md)
			<span style="font-size: 16px; color: #D5E0A0">双肺散在/广泛性啰音</span>：[慢性支气管炎](慢性支气管炎)
<mark style="background-color: #705A16; color: white">胸膜磨擦音</mark>
	胸膜磨擦音在吸气和呼气时都可听到，以吸气末或呼气初较为明显，屏住呼吸时消失；胸膜摩擦音在<mark style="background-color: #1A4F10; color: white">前下侧胸壁最强</mark>
	会受到体位影响
	胸膜摩擦音的临床意义:  胸膜摩擦音是<mark style="background-color: #1A4F10; color: white">干性胸膜炎</mark>的重要体征，常见于: 
		①胸膜炎症，[[结核性胸膜炎]]和化脓性胸膜炎；
		②原发性或继发性胸膜肿瘤；
		③肺部病变累及胸膜，如[[肺炎]]，[[肺梗死]]；
		④[[尿毒症]]。
