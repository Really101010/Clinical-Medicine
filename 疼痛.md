| 疼痛类型 | 特点              | 好发部位      | 病机                                                                                                                                 |
| ---- | --------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 胀痛   | 疼痛伴有胀感          | 胸胁、脘腹、头面部 | <mark style="background-color: #1A4F10; color: white">气滞</mark>（热气滞）                                                               |
| 刺痛   | 针刺刀扎样痛          | 胸胁、脘腹     | <span style="font-size: 16px; color: #FFDEDE">瘀血</span>阻滞                                                                          |
| 冷痛   | 伴有寒冷感，得温减弱，遇寒加重 | 胸胁、脘腹、肢体  | 寒凝气<span style="font-size: 16px; color: #FFDEDE">血不通</span>                                                                        |
| 灼痛   | 伴有灼烧感，喜凉恶热      | 胸胁、脘腹     | 火热之邪                                                                                                                               |
| 重痛   | 疼痛有困/沉重感        | 头部、腰部、四肢  | <span style="font-size: 16px; color: #D5E0A0">湿邪</span>困阻气血                                                                        |
| 酸痛   | 局部酸痛难忍，多有诱因     | 肢体、腰膝     | <span style="font-size: 16px; color: #D5E0A0">湿邪</span>困阻（发于肢体），肾虚（发于腰膝）                                                           |
| 绞痛   | 疼痛剧烈，如刀绞        | 胸胁、脘腹部    | <span style="font-size: 16px; color: #FFDEDE">瘀血</span>、结石、寒凝（<mark style="background-color: #1A4F10; color: white">寒气滞</mark>）、虫积 |
| 隐痛   | 轻微但连绵不止，呈持续性    | 头部、胸胁、脘腹  | <span style="font-size: 16px; color: #FFDEDE">精血亏虚</span>筋脉失养，或<span style="font-size: 16px; color: #FFDEDE">阳虚内寒</span>机体失温       |
| 走窜痛  | 痛处不固定           | 多处        | 多为<mark style="background-color: #1A4F10; color: white">风邪、气滞</mark>导致                                                             |
| 固定痛  | 痛处固定不移          | 局部        | 寒凝、瘀血阻滞                                                                                                                            |
