指人对周围环境及自身状态的识别和觉察能力出现障碍。
发生机制：感染/中毒/机械压迫
	重症急性感染：败血症、肺炎、中毒型菌痢
	<span style="text-decoration: underline;">颅脑非感染性疾病</span>：脑缺血、脑出血、高血压脑病、脑肿瘤
	内分泌和<span style="text-decoration: underline;">代谢</span>性障碍：尿毒症、肝性脑病、肺性脑病、甲状腺危象、甲状腺功能减退
	水、电解质平衡紊乱：低钠血症、低氯性碱中毒、高氯型酸中毒等
	外源性中毒：有机磷杀虫药、CO

| 类型                                                                | 定义                                                                                                                                                                                                             |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 嗜睡                                                                | 一种病理性倦睡，患者陷入持续的睡眠状态，可被唤醒，并能正确回答和做出各种反应，但当刺激去除后很快又再入睡。                                                                                                                                                          |
| <mark style="background-color: #1A4F10; color: white">意识模糊</mark> | 意识水平轻度下降，较嗜睡为深的一种意识障碍。患者能保持简单的精神活动，但对时间、地点、人物的<mark style="background-color: #1A4F10; color: white">定向能力</mark>发生障碍。                                                                                           |
| 昏睡                                                                | 接近于人事不省的意识状态。患者处于熟睡状态，不易唤醒。虽在强烈刺激下（ 如压迫眶上神经，摇动患者身体等）可被唤醒，但很快又再入睡                                                                                                                                               |
| 昏迷                                                                | 严重的意识障碍，表现为意识持续的中断或完全丧失。按其程度可分为三阶段。<br><span style="font-size: 16px; color: grey">轻度昏迷：角膜反射、瞳孔对光反射、眼球运动、吞咽反射等可存在<br>中度昏迷：角膜反射减弱，瞳孔对光反射迟钝，眼球无转动。<br>深度昏迷：全身肌肉松弛，对各种刺激全无反应。深、浅反射均消失。</span><br>? 可参考麻醉过程评估 #idea |
| 谵妄                                                                | 以兴奋性增高为主的高级神经中枢急性活动失调状态，表现为意识模糊、定向力丧失、感觉错乱（ 幻觉、错觉）、躁动不安、言语杂乱。                                                                                                                                                  |
伴随症状
	1.伴瞳孔缩小：吗啡类、巴比妥类、有机磷杀虫药等中毒
	2.伴皮肤黏膜改变、出血点、瘀斑和紫癜：严重感染和出血性疾病
	3.伴口唇呈樱红色：一氧化碳中毒
	4.伴心动过缓：<span style=".underline {   text-decoration: underline; }">可见于颅内高压症、房室传导阻滞以及吗啡类、毒蕈等中毒</span>
