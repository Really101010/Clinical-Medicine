#### 概念
指人对周围环境及自身状态的识别和觉察能力出现障碍。
在意识清晰度下降的同时**伴有定向力下降**
意识是指个体对外界环境、自身状况以及它们相互联系的确认。
##### ①觉醒状态(waking state): 
指与睡眠呈周期性交替的清醒状态。
上行网状激活系统(ascending reticular activating system)和大脑皮质广泛损害可导致觉醒障碍。
##### ②意识内容(conscious content)：
指感知、思维、记忆、注意、智能、情感和意志活动等心理过程。
大脑皮质病变常导致其变化。
#### 发生机制：
感染/中毒/机械压迫
- 重症急性感染：败血症、肺炎、中毒型菌痢、寄生虫病（如脑型[疟疾](疟疾.md)、脑[血吸虫病](血吸虫病.md)、脑棘球蚴病、脑囊虫病等）
- <span style="text-decoration: underline;">颅脑非感染性疾病</span>：[脑缺血](缺血性脑病.md)、[脑出血](脑出血.md)、[高血压脑病](高血压脑病.md)、[脑肿瘤](脑肿瘤.md)
- 内分泌和<span style="text-decoration: underline;">代谢</span>性障碍：[尿毒症](尿毒症.md)、[肝性脑病](肝性脑病.md)、[肺性脑病](肺性脑病.md)、甲状腺危象、[甲状腺功能减退](甲状腺功能低下.md)
- 水、电解质平衡紊乱：低钠血症、低氯性碱中毒、高氯型酸中毒等
- 外源性中毒：有机磷杀虫药、CO
#### 分类与表现
##### ①以觉醒度改变为主的意识障碍

| 类型                                                                | 定义                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 嗜睡somnolence                                                      | 一种病理性倦睡，患者陷入持续的睡眠状态。<br>可被唤醒，并能<mark style="background-color: #1A4F10; color: white">正确</mark>回答和做出各种反应，但当刺激去除后很快又再入睡。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| <mark style="background-color: #1A4F10; color: white">意识模糊</mark> | 意识水平轻度下降，较嗜睡为深的一种意识障碍。患者<mark style="background-color: #1A4F10; color: white">能保持简单的精神活动</mark>，但对时间、地点、人物的<mark style="background-color: #1A4F10; color: white">定向能力</mark>发生障碍。<br>急性意识模糊状态的注意力不集中，错觉为突出表现，幻觉少见。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 昏睡stupor                                                          | 接近于人事不省的意识状态。患者处于熟睡状态，不易唤醒。<mark style="background-color: #1A4F10; color: white">较重的痛觉或言语刺激</mark>（强烈刺激如压迫眶上神经，摇动患者身体等）能唤醒，能作简短、模糊地回答，醒时答非所问，<mark style="background-color: #1A4F10; color: white">不能配合检查</mark>，刺激停止后立即熟睡。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 昏迷                                                                | 严重的意识障碍，表现为意识持续的中断或完全丧失。按其程度可分为三阶段。<br>轻度昏迷：对强烈刺激（如压迫眶上缘）有反应，<mark style="background-color: #1A4F10; color: white">各种反射存在</mark>（<mark style="background-color: #3F4B5E; color: white">角膜反射、瞳孔对光反射、眼球运动、吞咽反射</mark>等可存在），生命体征正常。<br>中度昏迷：介于深浅昏迷之间，<mark style="background-color: #1A4F10; color: white">对一般刺激无反应，强刺激可见防御反射</mark>，深浅反射减弱，呼吸节律可改变。<mark style="background-color: #3F4B5E; color: white">疼痛刺激（上臂内侧皮肤较薄区域）无反应。角膜反射减弱，瞳孔对光反射迟钝，眼球无转动，腱反射减弱/消失。</mark><br>深度昏迷：对<mark style="background-color: #1A4F10; color: white">各种刺激全无反应</mark>。<mark style="background-color: #3F4B5E; color: white">全身松弛，眼球固定，瞳孔散大</mark>，深、浅反射均消失。<mark style="background-color: #1A4F10; color: white">生命体征不稳</mark>。<br><span style="font-size: 16px; color: #FF0000">? </span>可参考麻醉过程评估 #idea |

##### ③特殊类型的意识障碍
###### 最低意识状态（minimally conscious state）：
存在微弱而肯定的对自身和环境的认知，有<mark style="background-color: #3F4B5E; color: white">自发睁眼和觉醒-睡眠周期</mark>。
