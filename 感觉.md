定义与基本特征：
人脑对直接作用于感觉器官的客观事物的<mark style="background-color: #1A4F10; color: white">个别</mark>属性的反映，是<mark style="background-color: #705A16; color: white">最基本</mark>的认知过程。

### 感觉障碍
#### 1、概述
##### （1）分类：
浅感觉（痛觉、温度觉及触觉）、深感觉（运动觉、位置觉及振动觉）、复合感觉（实体觉、图形觉、两点辨别觉、皮肤定位觉和重量觉）
##### （2）节段性感觉性支配：
每一个脊髓神经后根支配一定的皮肤区域，称为皮节。多数皮节由 2~3 个后根重叠支配，2 个以上后根损伤才出现感觉障碍。因而要确定脊髓损害的真正上界，须比感觉障碍平面高 1至 2 个节段来计算。
###### 有重要定位意义的部位：
◼ 乳头平面：T4
◼ 脐平面：T10
◼ 腹股沟：T12 和 L1
◼ 上肢：C5-T2
◼ 下肢：L1-S2
◼ 肛周鞍区: S3-5(由外向内)

| 分类                             | 术语                                  | 定义 / 描述                                                                                                                                                                                               |
| ------------------------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **抑制性症状：**  <br>感觉径路损害或功能受到抑制  | 感觉缺失 anesthesia / 感觉减退 hypoesthesia | 意识清楚时对刺激不发生感觉反应或反应减弱  <br>*分离性感觉障碍：同一部位仅有某种感觉（如痛觉、温度觉）缺失，而其他感觉（如触觉）保存。常见于脊髓空洞症                                                                                                                        |
| **刺激性症状：**  <br>感觉径路受到刺激或兴奋性增高 | 感觉过敏 hyperesthesia                  | 给予轻微的刺激却引起强烈的感觉                                                                                                                                                                                       |
|                                | 痛觉过敏 hyperpathia                    | 接受刺激后，需经一潜伏期，才能感受到强烈的、定位不明确的、向四周扩散的痛或不适的感觉，持续一段时间后才消失                                                                                                                                                 |
|                                | 感觉异常 paresthesia                    | 没有受到外界刺激而产生的异常感觉                                                                                                                                                                                      |
|                                | 感觉倒错 desesthesia                    | 对刺激感受的认识错误，非疼痛性刺激而产生疼痛感觉，如触觉刺激产生痛觉，冷刺激产生热感觉                                                                                                                                                           |
