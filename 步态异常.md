| 步态类型                                  | 表现                                                                                                                                                                   | 定位                                                                                                                                                              |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **偏瘫步态**  <br>hemiplegic gait         | 单侧身体姿势异常：病侧上肢屈曲、内旋，下肢伸直；行走时下肢呈划圈状，又称“划圈步态”                                                                                                                           | 一侧锥体束病变                                                                                                                                                         |
| **跨阈步态**  <br>steppage gait           | 足下垂，行走时为避免足趾摩擦地面，<mark style="background-color: #1A4F10; color: white">过度抬高下肢</mark>，如跨门槛的动作                                                                         | 下运动神经元损害导致胫前肌和腓肠肌无力。<br>见于<mark style="background-color: #1A4F10; color: white">腓总神经</mark>麻痹                                                                   |
| **肌病步态**  <br>waddling-myopathic gait | 行走缓慢，腰部前挺，臀部左右摇摆                                                                                                                                                     | 肌营养不良                                                                                                                                                           |
| **剪刀步态**  <br>scissor gait            | 双下肢强直内收，尤以伸肌和内收肌张力增高明显，行走时一前一后<mark style="background-color: #1A4F10; color: white">交叉</mark>呈剪刀样，足尖拖地。                                                              | 见于双下肢痉挛性瘫痪（<mark style="background-color: #1A4F10; color: white">截瘫</mark>即脊髓横贯性损伤或者<mark style="background-color: #1A4F10; color: white">脑性瘫痪</mark>即双侧大脑半球病变） |
| **蹒跚步态**  <br>ataxia gait             | ~~行走时步基增宽，左右摇摆，前扑后跌，不能行走直线，犹如醉酒状。~~<span style="font-size: 16px; color: #FF0000">？？？</span><br>走路时骨盆及躯干摇摆明显，呈<span style="font-size: 16px; color: #D5E0A0">鸭步</span> | ~~小脑、前庭或深感觉传导通路病变~~<br>见于[佝偻病](佝偻病.md)、大骨节病、<mark style="background-color: #1A4F10; color: white">肌营养不良、髋关节脱位或进行性肌病</mark>等                                     |
| **慌张步态**  <br>festination gait        | 行走时躯干前倾，双上肢缺乏联带动作，步幅小，<mark style="background-color: #1A4F10; color: white">起步和停步困难</mark>；躯干重心前移，行走时往前追逐重心，小步加速似慌张不能自制                                              | 见于[Parkinson 病](Parkinson%20病.md)                                                                                                                               |
| 醉酒步态                                  | 行走时躯干重心不稳，步态紊乱不能走直线。                                                                                                                                                 | 见于[小脑病变](小脑病变.md)（如小脑出血、肿瘤）或[[前庭功能障碍]]、<mark style="background-color: #1A4F10; color: white">酒精及巴比妥中毒</mark>                                                    |
